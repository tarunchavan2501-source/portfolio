# Tarun Chavan | Portfolio

A responsive personal portfolio website for **Tarun S Chavan**, a B.Tech Computer Engineering student at Dr. D. Y. Patil College of Engineering & Innovation (DYPCOEI), Pune.

🔗 **Live site:** https://tarun-chavan-portfolio.netlify.app

## About
This site presents my projects, certifications, and skills in software development, AI/ML, Python GUIs, and embedded IoT systems. It also includes a section on my college and faculty, including an academic tribute to Principal Dr. Suresh Mali.

## Features
- Animated hero section with an interactive 3D tilt card
- Projects section with live demos and GitHub links
- Internship and certification gallery with a lightbox viewer
- **AI Lab:** type a project idea and get a suggested tech stack, color palette, and development advice
- Contact form powered by Web3Forms
- Smooth scrolling, custom cursor, and mobile-friendly navigation

## Built With
- HTML5, CSS3, and vanilla JavaScript
- GSAP and ScrollTrigger (animations)
- Lenis (smooth scrolling)
- Lucide (icons)
- Web3Forms (contact form)
- Hosted on Netlify
